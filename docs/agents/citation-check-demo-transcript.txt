Reproducing this
-----------------

Either run the CLI exactly as above (requires the `claude` CLI on PATH and
authenticated, and network access to fetch `CONTEXT.md` off GitHub), or run
the equivalent, asserted, pytest test:

    pytest -m network tests/test_citation_check_live.py -v

`test_the_automated_judge_tells_the_true_claim_from_the_wrong_one` in that
file makes the same two calls (fetch + automated judge) and asserts
`majority-true == SUPPORTED`, `majority-false == CONTRADICTED`, and that the
two differ — so a stale transcript here doesn't matter: the test is the
actual, current proof, this file is one recorded run of it.

Model output is not deterministic between runs — a different phrasing in
`detail`, or occasionally a `unclear` verdict on a rerun, would not be a
regression. What must hold is that the true and false claims never land on
the same verdict, which is exactly what the pytest assertions check.
