# State flag assets

These SVGs are Wikimedia Commons files, downloaded locally so the map does not
hotlink third-party artwork. The state set is indexed at:

https://commons.wikimedia.org/wiki/Category:SVG_flags_of_states_of_Malaysia

Federal-territory sources:

- https://commons.wikimedia.org/wiki/File:Flag_of_Kuala_Lumpur,_Malaysia.svg
- https://commons.wikimedia.org/wiki/File:Flag_of_Putrajaya.svg
- https://commons.wikimedia.org/wiki/File:Flag_of_Labuan.svg

Refer to each Commons file page for its author and reuse terms.
